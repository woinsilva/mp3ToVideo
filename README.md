# Video SaaS MVP

Base do projeto para o MVP de geracao de videoclipes.

## Modulo 1

Este repositorio inicia com:

- monorepo `pnpm`
- API NestJS
- Worker NestJS
- Frontend Vue 3 + Vuetify
- PostgreSQL via Docker Compose
- Redis via Docker Compose

## Comandos

```bash
docker compose up -d
pnpm install
pnpm dev
```
